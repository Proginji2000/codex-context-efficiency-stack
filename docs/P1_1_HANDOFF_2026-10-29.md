## Étape suivante recommandée

**D'abord :** inspecter le dernier état GitHub et `git pull --ff-only` local, puis faire le **mode plan sans modèle**, sur de nouveaux chemins. Fermer toutes les sessions Codex utilisant les profils V5 avant les contrôles et les restaurations éventuelles.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location 'C:\Dev\codex-context-efficiency-stack'
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'STOP: Git pull failed' }

    $py = 'C:\Dev\Python31314\python.exe'
    $bin = 'C:\Dev\codex-cli-0165\node_modules\.bin'
    $cli = Join-Path $bin 'codex.cmd'
    $script = '.\scripts\Run-CodexAB-V5-RepeatPairs.py'
    $pilot = 'C:\Dev\codex-ab-pr14-pilot-v5-0165'
    $base = 'C:\Dev\codex-ab-tui-mxc-v5-0165-v3'
    $oldPath = $env:PATH

    try {
        $env:PATH = "$bin;$oldPath"
        & $py .\scripts\Test-Run-CodexAB-TUI-Canary.py
        if ($LASTEXITCODE -ne 0) { throw 'STOP: TUI synthetic tests failed' }
        & $py .\scripts\Test-Run-CodexAB-V5-RepeatPairs.py
        if ($LASTEXITCODE -ne 0) { throw 'STOP: Repeat synthetic tests failed' }
        & $py $script --pilot $pilot --codex-cli $cli `
            --output-base $base --start-pair 4 --pairs 2
        if ($LASTEXITCODE -ne 0) { throw 'STOP: Planning failed' }
        Write-Host 'P1.1_V3_PLAN_READY_NO_MODEL'
    }
    finally { $env:PATH = $oldPath }
}
```

Ce plan n'exécute **aucun modèle** et ne modifie pas le pilote. Si deux configurations TOML ont simultanément dérivé, **STOP sans restauration forcée**. Le lanceur ne doit restaurer qu'un seul TOML à partir de l'autre, lui-même attesté par le hash enregistré ; chaque restauration produit un backup audit.

**Ensuite, seulement sur validation explicite de l'utilisateur**, exécuter avec les mêmes chemins l'option `--audited-restore --execute` qui peut lancer **quatre TUI payants maximum**, en séquence ; aucune relance automatique d'un résultat raté, aucun contournement d'accès, aucune copie de jetons ou désactivation de MXC. Le mode interactif peut demander à l'utilisateur `Trust this folder` sur les nouveaux dépôts jetables : c'est une décision manuelle distincte de l'approbation de commande.

Le prochain assistant doit collecter les quatre sorties (ou la sortie partielle si STOP), les compteurs `Token usage` des TUI, les rapports JSON sans secrets, et exécuter seulement des inspections offline sur les outputs existants.
